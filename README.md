# Expense Tracker

A simple web-based expense tracker designed to help users record and manage their daily expenses.

## Features

- Add expenses
- Select expense categories
- View recorded expenses
- Simple and clean interface
- Calm, nature-inspired colour palette

## Technologies Used

- HTML
- CSS
- JavaScript

## Future Improvements

- Expense editing and deletion
- Expense charts and visualizations
- Local storage for saving data
- Monthly expense summaries
